DeathRollForever host window, v2 mockup

One movable window, 300 by 420 px by default and the same size in every state; a grip in the bottom-right corner resizes it (try it) and long lists scroll inside. The corner holds an X to close it when no game is live and Cancel while one is; the window stays open during a game. /dr show opens it on the form. The main button reads Start, Roll or Reset by state. The tint and the icon come from the host's own faction.
