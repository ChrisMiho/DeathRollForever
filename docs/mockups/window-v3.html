Same 300 by 420 window, same title bar, subtitle, list box, status line, bar and main button as today. New: the ? in the title bar (click it here; in game it opens on hover), the list sorted by roll with the highest and lowest rows highlighted, and the result built around one debt.

Players still to roll sit at the top, dimmed, so the call-out is easy; they drop into place when they roll. Roll is enabled until you have rolled, then gray. The bar is the 45 s window.
